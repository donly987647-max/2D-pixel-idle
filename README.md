# 마왕의 전선 · 2D Pixel Idle

마왕의 몬스터들이 침입하는 용사를 자동으로 막는 2D 픽셀 방치형 디펜스 초안입니다. 가칭은 **마왕의 전선 (Nightkeep)** 입니다.

**플레이:** https://nightkeep-pixel-idle.vercel.app/

**배포 버전:** 0.1.1

## 플레이

게임을 열면 해골 병사 한 마리로 자동 전투가 시작됩니다. 전장의 몬스터나 하단 카드를 누르고 무기 / 방어구 / 유물 슬롯을 선택하면 장착, 해제, 강화할 수 있습니다. 시작 보관함에는 창, 철갑, 부적이 있습니다.

침입 2 방어 후 오크(150 금화), 침입 4 방어 후 리치(300 금화)를 영입할 수 있습니다. 몬스터는 쓰러져도 6초 후 부활합니다. 던전의 심장이 파괴되면 장비와 성장을 유지한 채 이전 단계에서 반복 파밍합니다.

가로 화면 권장. 세로 화면에서는 전장을 확대하고 하단 군단 카드를 세로로 배치합니다. 배속은 1× / 2× / 3×, 지옥불 강림은 22초 재사용 대기시간이 있습니다. 자동 돌파를 끄면 현재 침입을 반복합니다.

## 초안에 포함된 기능

- 오리지널 Canvas 픽셀 배경, 몬스터 / 용사 스프라이트, 무기 레이어, 용암 / 공격 이펙트.
- 몬스터 3종: 해골 병사, 오크 파괴자, 잿빛 리치.
- 무기 6종: 검, 관통창, 도끼, 망치, 화염 지팡이, 냉기 지팡이.
- 무기별 단일 / 관통 / 광역 / 밀치기·낙사 / 폭발 / 둔화 공격.
- 방어구 2종, 유물 1종. 일반 / 희귀 / 영웅 등급과 확정 강화(+20 한도).
- 몬스터 개별 레벨업(Lv.200 한도), 전리품, 장비 분해 및 강화 마석 회수.
- 일반 용사, 도적, 방패병, 치유 사제, 5단계마다 기사단장 보스.
- 기기 자동 저장, 저장 파일 내보내기 / 불러오기, 최대 4시간 오프라인 금화·마석 보상.

## 실행과 빌드

런타임 라이브러리, 외부 이미지, 외부 폰트, 서버 데이터베이스는 사용하지 않습니다.

```sh
node build.mjs
python -m http.server 4173 --directory public
```

브라우저에서 `http://localhost:4173`을 엽니다. `public/index.html`은 모든 그래픽·스타일·스크립트가 포함된 단일 파일입니다. 파일로 직접 열 수도 있으나 브라우저에 따라 로컬 파일 저장소 동작이 다를 수 있습니다.

`index.html`은 최초 작성한 0.1.0 게임 소스입니다. `build.mjs`는 0.1.1 모바일 비율 / 터치 좌표 / 알림 개수 수정 사항을 적용해 최종 정적 HTML을 생성합니다. 다음 구조 개편 시 이 작은 빌드 변환은 게임 소스에 통합할 예정입니다.

Vercel은 `vercel.json`의 정적 빌드를 사용합니다. 현재 공개 배포는 연결 도구를 통해 직접 배포했으며, GitHub push의 자동 Vercel 배포 연결은 설정하지 않았습니다. 소스 변경 후 별도 재배포가 필요합니다.

## 검증

```sh
npm install
npx playwright install chromium
node build.mjs
# 배포용 HTML로 테스트하려면 public/index.html을 임시 작업 폴더의 index.html로 사용합니다.
npm test
```

GitHub Actions의 `Prototype QA`에서 초기 상태, 장착, 강화 비용, 자동 전투 진행, 3종 영입, 저장 복원, 패배 후 파밍, 지옥불 대기시간, 오프라인 보상 한도, 저장 입력 검증, 반응형 화면, 런타임 오류를 검사합니다. QA 보고서와 스크린샷은 해당 실행의 artifact에서 확인할 수 있습니다.

## 현재 범위와 제한

실제 출시 버전이 아닌 전투 / 장비 루프를 확인하는 초안입니다. 던전 건설, 대규모 소환 군단, 몬스터 배치 편집, 계정 로그인 / 클라우드 저장, 장기 경제 밸런스, 모바일 앱 패키징은 포함하지 않았습니다.

저장은 접속 도메인과 브라우저에 종속됩니다. 브라우저 데이터를 지우면 진행이 삭제될 수 있으므로 설정의 저장 파일 기능을 이용하세요. 오프라인 보상은 최고 방어 단계를 이용한 수식 보상이며 실제 서버 전투 시뮬레이션은 아닙니다. 기기 시간 및 로컬 저장 파일을 사용하는 싱글플레이 프로토타입이므로 경쟁 게임용 치트 방지 기능은 없습니다.

다른 게임의 소스 / 이미지 / 사운드는 사용하지 않았습니다. 다른 기존 게임 저장소는 변경하지 않았습니다.
