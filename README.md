# 고철에서 우주까지 · Orbit Foundry

슬롯 동력기로 몬스터를 사냥하고, 장비를 강화하며, 황무지의 캠프를 우주선 발사 기지로 성장시키는 2D 픽셀 방치형 게임입니다.

**버전: 0.1.0 · 첫 우주선 발사까지 구현된 플레이 가능한 시제품**

## 실행

`index.html` 하나에 화면, 스타일, 게임 로직, 그림과 효과음이 모두 들어 있습니다. 외부 라이브러리나 빌드 과정이 없습니다.

저장소를 내려받아 `index.html`을 브라우저에서 여세요. 정적 웹 서버에서도 그대로 실행됩니다.

```sh
python -m http.server 8080
```

그다음 `http://localhost:8080`을 엽니다. 저장소의 GitHub 파일 보기 화면은 게임 실행 화면이 아닙니다. 별도의 공개 웹 호스팅 주소는 아직 설정되지 않았습니다.

## 플레이 흐름

`개척 시작`을 누르면 슬롯과 전투가 자동 진행됩니다. 슬롯은 무료이며 서로 다른 심볼도 각각의 기본 효과를 줍니다. 먼저 건설 세팅으로 작업장을 짓고, 장비를 강화한 뒤 지역 보스에 도전하세요. 보스를 격파한 후에는 지역 지도 또는 다음 지역 버튼으로 이동합니다.

건설 순서는 **작업장 → 대장간 → 자동화 공장 → 연구소 → 발사대 → 개척선 ORBIT-01**입니다. 보스 3마리가 주는 코어 4개는 이후 건설에 모두 사용됩니다. 발사 버튼을 누르면 우주선이 이륙하고 결과 화면이 표시됩니다. 기지와 장비는 초기화되지 않습니다.

## 구현된 기능

- 무료 3릴 자동 슬롯, 사냥·돈벌이·건설 확률 세팅, 2개·3개 일치, 12회마다 과충전.
- 기본 자동 공격, 보호막, 레벨업, 3개 지역과 3종 보스. 보스전은 90초이며 실패해도 자원 손실이 없습니다.
- 무기 4종, 방어구 3종, 장신구 3종. 부위별 확정 강화와 강화 수치 승계. 캐릭터 또는 장비를 눌러 교체합니다.
- 건물의 외형 변화, 공사 가속과 최대 100의 저장 작업력, 생산시설, 슬롯 동력 회로 개조.
- 로켓 단계별 조립, 발사 연출, 첫 궤도 진입 결과 화면.
- 모바일·데스크톱 반응형 화면, 직접 그린 Canvas 픽셀 그래픽과 SVG 심볼.
- 브라우저 자동 저장, JSON 파일 내보내기·불러오기, 음소거, 화면 효과 감소, 테스트용 2배속.

## 저장과 오프라인

저장은 현재 브라우저의 `localStorage`에만 보관됩니다. 클라우드 동기화는 없습니다. 브라우저 데이터 삭제, 비공개 모드, 파일 경로/도메인 변경 시 기록이 사라지거나 다른 기록으로 보일 수 있으므로 중요한 진행은 설정에서 **파일 백업**을 사용하세요. 저장 접근이 차단되면 화면 하단에 안내합니다.

오프라인 보상은 최대 **8시간**의 기본 골드·고철 생산과 이미 착공한 공사입니다. 오프라인 슬롯 추첨, 사냥 보상, 보스 격파는 계산하지 않습니다. 공사가 완료되면 남은 시간에는 완성 후 생산량을 적용합니다.

## 범위와 확인 사항

현재는 첫 우주선 발사까지의 시제품입니다. 추가 행성, 환생, 장비 랜덤 드롭, 수백 종의 장비, 결제, 광고는 구현되어 있지 않습니다. 실제 돈을 거는 기능도 없습니다.

개발 환경에서 Chromium 화면·버튼 동작, 모바일 가로 넘침, 슬롯 125개 결과 조합, 오프라인 상한과 공사 완료 후 생산, 저장 데이터 유효성 검사, 자원 추가 없이 전체 건설·보스·발사 진행을 확인했습니다. 자동 진행 테스트는 실제 플레이 난도나 모든 브라우저 호환성을 보장하지 않습니다. 로컬 자동화 환경은 저장소 접근이 제한되어 실제 브라우저 재접속 저장은 별도 검증 대상입니다.

## 개발

게임 데이터는 `BUILDINGS`, `ZONES`, `EQUIP`, `WEIGHTS`에, 진행 처리는 `tick()`, 슬롯 결과는 `settleSpin()`, 픽셀 화면은 `draw()`에 있습니다. 저장 키는 `orbit-foundry-v1`입니다.

파일에 외부 에셋, 추적 코드, 서버 API 호출, 비밀키가 없습니다.
